# Security policy

The current `main` branch is supported for security fixes.

## Report a vulnerability privately

Use [Report a vulnerability](https://github.com/parthg1901/windlass-platform/security/advisories/new)
to send the maintainer a private report. Keep vulnerability details out of public issues,
discussions and pull requests.

Reports are in scope for the web app, server, runner, sandbox integrations and self-host
configuration in this repository. Examples include unauthorized access to a session, exposure
of credentials, and failures of sandbox isolation. Include the affected commit, configuration,
observed impact and steps to reproduce on a system you control. Redact tokens, keys and user data.
If the defect is in an upstream component, explain how it affects the platform here.
