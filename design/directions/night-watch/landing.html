You choose where an agent runs when you start it, and see its layers before it starts. Your sign-in never goes in: each turn is lent a short-lived token.

Your machine

A runner that connects out

Pair a Linux machine with Docker. A small runner dials out to the platform and runs each session in a container. Nothing on your machine has to be reachable.

1Docker container

non-root, no capabilities, seccomp, limits

2Windlass sandbox, per command

no network, writes only in the workspace

the agent's commands
$ docker run -d --name windlass-runner \
    -v /var/run/docker.sock:/var/run/docker.sock \
    <runner image> --platform <address>

The Windlass sandbox profile is the strict one: a command that wants the network or a write outside the workspace asks you first. The hardened profile runs commands directly in the container, with network — the launch form says which promise each profile makes.
